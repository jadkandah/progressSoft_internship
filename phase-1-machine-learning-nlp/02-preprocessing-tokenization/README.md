# Phase 1.2 — Text preprocessing and tokenization

This is an intentionally incomplete learning skeleton. Implement the TODOs
yourself and explain your decisions in the notebook.

## Suggested order

1. Open `notebooks/text_preprocessing.ipynb` and complete it from top to bottom.
2. Implement preprocessing functions in `src/preprocessor.py`.
3. Implement tokenizers in `src/tokenizer.py`.
4. Complete the NLTK and spaCy comparison scripts.
5. Implement corpus and N-gram statistics in `src/text_statistics.py`.
6. Return to the notebook to run the full dataset and write observations.

## Files

```text
data/IMDB Dataset.csv             # downloaded dataset, retained for convenience
data/data_retreival.ipynb         # optional download helper
notebooks/text_preprocessing.ipynb
src/preprocessor.py
src/tokenizer.py
src/nltk_comparison.py
src/spacy_comparison.py
src/text_statistics.py
```

Each source file has a checklist at the top. Check items only after you can
explain and test your implementation.
